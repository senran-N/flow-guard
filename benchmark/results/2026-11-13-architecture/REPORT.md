## 实际发现及修复

1. 导入注册引用排在真实调用之前，会把执行关系归成注册，导致合法任务路径丢失。按调用点类别分别保留边，移除以调用者函数名称推断注册的规则；Rust 已证明的回调调用保留执行语义。源码回归及两版 SDK 路径检查通过。
2. 大候选集使 Bruno 显式 2000 边查询输出约 32 MB。预览限制为 8 个候选、3 个实参位置，保留总数与完整检索分页；最大页仍可能数 MB，默认页数据量见上表。
3. 大量未知协议端点可能挤掉默认页的源码模块。同焦点距离下改为源码节点优先、稳定 ID 排序；80 个未知端点反例通过。
4. 同步文档曾固定声称目录分组，改为引用实际 grouping；本项目增加显式业务模块配置，指南示例使用真实模块 ID。

## 尚存边界

任意语言、宏、反射、动态插件和运行期协议的完整架构不能由当前静态分析保证。候选不等于调用，IMPORT 不等于执行，路径不证明值传播或运行行为。文件导入专门覆盖 JS/TS/Vue/Svelte，其余语言沿用既有调用与桥接解析。状态位置是所属声明，持久化只有命名线索。分页和搜索须检查省略量及 complete。Git 比较描述节点/关系增删，不单列相同 ID 的标签、层级、统计及证据内容更新。

本次完成已定义功能与验证，仍不能宣称“架构视野绝对完美”。
